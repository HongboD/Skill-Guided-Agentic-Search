# Anonymous release

This release uses an anonymous project identity, an anonymous citation record, and a fresh Git history. It includes no author affiliation, personal profile link, private path, or identifying remote configuration. Third-party software attribution, dataset-provider names, and cited research authors are preserved.

The release excludes benchmark datasets, full topic prompts, corpus excerpts, raw model traces, provider request identities, publisher PDFs, and local configuration. Model labels are retained because they are experimental factors.

Run scripts/check_release.py to check the tracked file scope, common credential/path patterns, and numerical result coverage. A content scan is useful evidence, not a guarantee against identification from the research itself.

Hosting metadata is separate from repository contents. Upload through an anonymous review mechanism or a neutral account if anonymity is required. A personally identifying hosting account, issue history, or earlier public commit remains identifying even if the new files are anonymous. No repository publishing is performed by this project.
